## 2026-07-11 — Final Evidence Closure: Ledger Full Recount

**Trigger:** R01 指示書 "Final Evidence Closure（Ledger Full Recount）" — close the project's last remaining Evidence Gap (Decision/Integrity Ledger aggregate counts, previously only spot-checked) via full recount, not sampling, and render final approval judgment.

But the "8 Open" figure stated in this project since v1.0 — never previously fully recounted, only spot-checked by the Independent Audit, which explicitly flagged it as unverified — is **incorrect**. The full, cross-validated recount found **21 Open, 10 Resolved (previously never stated), 0 Superseded** (21+10=31, exact match to total). This is a 62% undercount of the true Open figure, not a rounding error. **Corrections applied:** `03_RUNTIME_GOVERNANCE_SPECIFICATION.md` §4, `appendix/CORRECTIVE_ACTION_REPORT.md` (Remaining Issues item 1), `appendix/FINAL_VERIFICATION_REPORT.md` (Part 2 item 1, Part 3 verdict). `appendix/INDEPENDENT_AUDIT_REPORT.md` was **not modified** — its description of this figure as unverified remains an accurate description of that phase's own scope, even though the inherited "8" is now known to be wrong.

Root-cause note: the "8" figure was most likely an unverified estimate made during this project's original Phase 1 evidence-gathering (the full 31-record list had been retrieved inline in that session but not systematically tallied by status) — this project has no way to reconstruct the exact original reasoning, and does not attempt to guess further than that.

The corrected figure (21 of 31 Open, roughly two-thirds) more strongly supports this project's existing characterization of the Integrity Ledger as an actively-used, largely-unresolved internal risk register than the understated original ("8 of 31," roughly one-quarter) did.
